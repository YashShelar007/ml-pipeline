# Contributing

This repo is archived and not taking new features. Fixes to the docs are welcome.

1. Install: `pip install -r requirements.txt` (TensorFlow 2.13, so Python 3.8 to 3.11).
2. There is no test suite. The CI workflow's lint and test steps are `echo` placeholders.
3. Branch from `main`, keep the change small, and open a pull request that says what you ran.
